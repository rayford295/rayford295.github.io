## About

Yifan Yang is a Ph.D. student in the Department of Geography at Texas A&amp;M University, advised by [Dr. Lei Zou](https://www.geoearlab.com/people) in the [Geospatial Exploration and Resolution (GEAR) Lab](https://www.geoearlab.com). His research centers on Responsible GeoAI and Autonomous GeoAI for explainable spatial reasoning under incomplete, changing, and real-world observations.

He founded [AutonomousGeoAI4Science](https://github.com/AutoGeoAI4Sci), an open research initiative for papers, tools, benchmarks, and collaboration around autonomous GeoAI for science.

### Research Interests

- AI4Science · [Spatial Data Science](https://scholar.google.com/citations?view_op=search_authors&hl=zh-CN&mauthors=label:spatial_data_science) · GeoAI
- GIScience · Multimodal AI · Disaster Resilience · Generative AI

## Repository Structure

```text
_layouts/homepage.html  # Dedicated minimalist landing page and live clocks
_pages/about.md         # Canonical long-form profile and section source
_pages/*.md             # Dedicated pages for the site sections
_data/navigation.yml    # Main navigation
images/                 # Homepage artwork, logos, gallery, and media assets
assets/                 # Stylesheets, JavaScript, and downloadable materials
```

## Tech Stack

The site is built with [Jekyll](https://jekyllrb.com/) on top of the [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template and is deployed through GitHub Pages.

## Run Locally

```bash
git clone https://github.com/rayford295/rayford295.github.io.git
cd rayford295.github.io
bash run_server.sh
# Open http://127.0.0.1:4000
```
